Amit Sinhababu - Minimal academic homepage (Version 2)

This is a complete static website. No package installation or build is required.
Open index.html in your browser to preview it locally.

GITHUB PAGES
1. Create or open the repository named YOUR-USERNAME.github.io.
   The repository name must match your actual GitHub username.
2. Upload index.html, the complete assets folder, and .nojekyll to the root.
   Preserve assets/amit-sinhababu.jpg inside the assets folder.
   Do not upload the enclosing version-2 folder.
3. In Settings > Pages, select Deploy from a branch, main, and / (root), then Save.
4. Visit https://YOUR-USERNAME.github.io/ .
   Project repositories work as well: all local asset paths are relative.
